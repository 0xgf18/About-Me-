# Hi, I'm Fahad 👋

I am a developer and reverse engineer specializing in software modding, binary unpacking, and deobfuscation across **Android**, **Native Windows/Linux binaries (x86/x64)**, and **.NET assemblies**. I focus on bridging artificial intelligence with reverse engineering to automate complex security tasks and defeat commercial protections.

---

### 🛠️ Core Focus & Specialties
* **Unpacking & Protection Bypass:** Building custom AI-powered tools to unpack, decrypt, and deobfuscate binaries protected by commercial packers.
* **Multi-Platform Reversing:** 
  * **Android:** Dalvik/Smali bytecode patching, integrity bypasses, and DEX extraction.
  * **Native Binaries:** x86/x64 assembly analysis, static decompilation, and dynamic memory patching.
  * **.NET Assemblies:** MSIL analysis, metadata restoration, and custom obfuscator stripping.
